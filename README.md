# Проект "Трекер самолётов"

## Описание

Проект создан для удобного отслеживания самолётов и их информации относительно заданной страны. 
Проект "Трекер самолётов" позволяет пользователю, задав необходимую страну, 
получить данные о заданном топе или полном списке самолётов, и отфильтровать их по заданным странам регистрации.

### Модуль работы с API:

`api.py` - позволяет получать данные о странах и самолётах взаимодействуя с сайтами:
[nominatim.openstreetmap.org](https://nominatim.openstreetmap.org/ui/search.html) и 
[opensky-network.org](https://opensky-network.org/).

### Модуль обработки:

`aeroplanes.py` - обрабатывает всю получаемую информацию о самолётах.

### Модуль сохранения:

`jsonsaver.py` - сохраняет полученный вывод о данных в json-файл `aeroplanes.json`.

## Установка:

1. Клонируйте репозиторий:

`git@github.com:Dmitriy-Logvinenko/Project_2.git`

2. Установите зависимости:

`pip install -r requirements.txt`

## Использование:

1. Откройте свой терминал.
2. Запустите проект с помощью команды: `python main.py` или `python3 main.py`.
3. Введите название страны, в области которой будет произведён поиск по самолётам.
4. Введите число, для вывода топа самолётов.
5. Введите, через запятую, название стран, для фильтрации списка самолётов по стране регистрации.
